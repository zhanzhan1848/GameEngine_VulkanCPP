# Sequencer 渲染调试工作区

顶部 World Editor 是文档标签；底部 Content & Logs / Sequencer 是局部工具标签。点击底部 Sequencer，或按 F7 / View → Sequencer Panel 切换到时间轴。上方层级、渲染视口与 Inspector 始终保留，底部两页使用同一高度；切换不会移动、缩放或重新挂载原生视口。

## 操作

1. 输入名称、FPS（1–120）、总帧数，点击 New；或 Open 打开 `.pseq`。
2. 在层级选中实体，点击 K 记录当前帧的位置、旋转、缩放；没有轨道时自动建轨。
3. 跳到另一帧，在 Inspector 修改变换，再点击 K。灯光移动、物体运动、相机运镜使用相同变换轨。
4. 拖动标尺、输入帧号、点击前后帧按钮或滚轮逐帧检查。Shift + 滚轮步进 10 帧。点击轨道名称可选中对应实体。
5. 时间轴获得焦点后，左右方向键逐帧，Home/End 到首尾，Space 播放/暂停，K 记录关键帧；输入框内打字不触发这些快捷键。
6. 选中 Camera 实体后点击 + Cut，添加当前帧起的 24 帧镜头（不超过序列末尾）。预览跳帧和播放自动切换相机，无镜头覆盖时回到编辑器相机。
7. Capture frame 保存当前姿态的 PNG 到 `项目/Captures/序列名/`，文件名含帧号和时间；状态栏显示完整路径。Render 导出整段 PNG，并按原有通道尝试用 ffmpeg 编码视频。
8. Save 保存到 `项目/Sequences/名称.pseq`。关键帧与镜头编辑复用现有 UndoRedo；右键关键帧或镜头删除，可撤销。

播放、拖动和逐帧共用 `sequence.*` 的求值路径；Inspector 同步显示求值后的坐标。跳帧属于预览态，不新增撤销记录，当前姿态会留在场景文档中。新建或打开其他序列前请先保存当前序列。

## 当前范围

这是变换与相机序列工作区。帧号决定场景姿态，但还没有引擎渲染时钟冻结、GPU 单步、GI/TAA 历史缓存重置或回放、Pass 断点、渲染参数轨或曲线编辑器。因此同一帧号不保证 GI/TAA 等带历史状态的像素完全一致，不能把它当作 GPU 确定性回放器。

## 验证

- 71 项相关测试通过，包含 CLI schema、序列求值和实际 Dock 布局及局部标签双向同步检查；切换前后视口尺寸、位置、实例与挂载状态均保持不变。
- 真实 Metal 编辑器：创建序列、记录灯光 F0/F119 关键帧、保存 `.pseq`、前进至 F1 并保存 PNG。
- CLI selftest、离线项目打包通过。
- 本地完整门禁的 C++/C# 构建、CLI 单测、离线渲染、网格处理、渲染基线和 VT 烘焙通过；最后的编辑器冒烟在 `editor.metrics` 第 0 帧 GPU 读回失败，完整门禁未通过。
