# WFC Phase A.3: Tiles + PCG Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the WFC solver to handle a real multi-tile catalog (cube, ramp, corner, pillar — 8 variants total), expose it through a `ParametricTileNode` PCGNode, and produce collapsed-cell instances as a `CGPointSet` via a new `WFCOutput` class. End of Phase A.3: an integration test runs the full pipeline (catalog → registry → solver → output → point set) on a 4×4×4 grid with hand-authored adjacency rules.

**Architecture:** CPU-only, no rendering (deferred to Phase A.4). Multi-tile candidate space is packed into the existing `u64 candidate_mask` via an 8×8 layout (bit index = `tile_id * 8 + variant`). The catalog owns tile metadata + adjacency rules as data, not code. `ParametricTileNode` is a thin PCGNode adapter that emits the catalog as a `CGPointSet`. `WFCOutput` is a standalone class (function-style) that walks the `WFCStepBuffer` and writes per-cell instance points.

**Tech Stack:** C++17, primal engine utilities, Phase A.1/A.2 foundation (`WaveGrid`, `TileAdjacencyTable`, `WFCSolver`, `WFCTileRegistry`, `WFCStepBuffer`, `WFCConfig`, `WFCTypes`), PCG graph system (`PCGNode`, `PCGPointSet`, `PCGParamDescriptor`), procedural mesh generators (`create_box_mesh`).

**Spec reference:** `Docs/superpowers/specs/2026-07-25-wfc-pcg-3d-map-generator-design.md` (sections 4 Phase A, 7.1 ParametricTileNode, 8.1 3D rendering path)

## Multi-tile Candidate Packing

Phase A.2 left a known limitation: bit index = variant of tile 0. Phase A.3 replaces this with explicit packing:

```
bit_index = tile_id * 8 + variant
         where variant < 8
```

- **8 tiles maximum** in any single solve (tile_id 0-7)
- **8 variants maximum** per tile (variant 0-7)
- Total 64 candidates fits exactly in `u64 candidate_mask`

This is a hard Phase A.3 limit. Phase B can extend to `utl::vector<u64>` if larger catalogs are needed.

**Files affected:**
- `WFCTileRegistry` defines the packing (Tasks 1-2)
- `WFCSolver::PopulateAllCandidates` and `CollapseCell` use registry helpers (Tasks 3-4)
- `WFCPropagator::RunPass` uses registry helpers (Task 5)

```cpp
void WFCSolver::PopulateAllCandidates(WaveGrid& grid, const WFCTileRegistry& registry) {
    // Phase A.3 multi-tile: iterate registry tiles, set bit for each (tile, variant)
    u64 full_mask = 0;
    for (u32 t = 0; t < registry.Count(); ++t) {
        const WFCTile& tile = registry.Get(wfc_tile_id{t});
        for (u32 v = 0; v < tile.variant_count; ++v) {
            u32 bit = WFCTileRegistry::BitForTileVariant(wfc_tile_id{t}, v);
            if (bit < 64) {
                full_mask |= (1ULL << bit);
            }
        }
    }
    u32 total_candidates = static_cast<u32>(__builtin_popcountll(full_mask));

    auto& cells = grid.CellsMutable();
    for (u32 i = 0; i < cells.size(); ++i) {
        WFCCell& c = cells[i];
        c.candidate_mask = full_mask;
        c.candidate_count = total_candidates;
        c.entropy = static_cast<u8>(total_candidates);
        c.collapsed = false;
        c.collapsed_tile = wfc_tile_id{0};
        c.collapsed_variant = 0;
    }
}
```

```cpp
void WFCSolver::CollapseCell(WaveGrid& grid, WFCGridCoord coord,
                             const WFCTileRegistry& registry) {
    WFCCell& c = grid.CellAt(coord);
    assert(c.candidate_count > 0);
    u32 pick = rng_.NextRange(c.candidate_count);

    // Walk set bits in candidate_mask; pick the (pick)-th
    u64 m = c.candidate_mask;
    u32 chosen_bit = 0;
    while (m) {
        u32 bit = __builtin_ctzll(m);
        if (pick == 0) {
            chosen_bit = bit;
            break;
        }
        m &= m - 1;
        --pick;
    }

    // Decode (tile, variant) from chosen_bit using registry packing
    wfc_tile_id chosen_tile = WFCTileRegistry::TileForBit(chosen_bit);
    u32 chosen_variant = WFCTileRegistry::VariantForBit(chosen_bit);

    c.candidate_mask = (1ULL << chosen_bit);
    c.candidate_count = 1;
    c.entropy = 0;
    c.collapsed = true;
    c.collapsed_tile = chosen_tile;
    c.collapsed_variant = chosen_variant;

    WFCStep step{};
    step.kind = WFCStepKind::Collapse;
    step.coord = coord;
    step.tile = chosen_tile;
    step.variant = chosen_variant;
    step_buffer_->Push(step);

    propagator_.OnCellCollapsed(grid, coord, chosen_tile, chosen_variant);
}
```

```cpp
                           const WFCTileRegistry& registry, bool& out_contradiction) {

    u32 changed = 0;

    utl::vector<WFCGridCoord> current_queue;
    current_queue.swap(dirty_queue_);

    for (WFCGridCoord c : current_queue) {
        WFCCell& cell = grid.CellAt(c);
        if (cell.collapsed) continue;

        u64 new_mask = cell.candidate_mask;
        u64 old_mask = cell.candidate_mask;

        static const struct { WFCFace my_face; WFCFace neighbor_face; s32 dx, dy, dz; } kFaces[] = {
            {WFCFace::PosX, WFCFace::NegX,  1,  0,  0},
            {WFCFace::NegX, WFCFace::PosX, -1,  0,  0},
            {WFCFace::PosY, WFCFace::NegY,  0,  1,  0},
            {WFCFace::NegY, WFCFace::PosY,  0, -1,  0},
            {WFCFace::PosZ, WFCFace::NegZ,  0,  0,  1},
            {WFCFace::NegZ, WFCFace::PosZ,  0,  0, -1},
        };

        WFCGridCoord size = grid.Size();
        for (auto& f : kFaces) {
            WFCGridCoord n{c.x + f.dx, c.y + f.dy, c.z + f.dz};
            if (n.x < 0 || n.x >= size.x) continue;
            if (n.y < 0 || n.y >= size.y) continue;
            if (n.z < 0 || n.z >= size.z) continue;
            const WFCCell& neighbor = grid.CellAt(n);
            if (!neighbor.collapsed) continue;

            u64 allowed = 0;
            u64 m = cell.candidate_mask;
            while (m) {
                u32 bit = __builtin_ctzll(m);
                m &= m - 1;
                wfc_tile_id my_tile = WFCTileRegistry::TileForBit(bit);
                u32 my_variant = WFCTileRegistry::VariantForBit(bit);
                if (adjacency.Compatible(my_tile, my_variant, f.my_face,
                                         neighbor.collapsed_tile, neighbor.collapsed_variant)) {
                    allowed |= (1ULL << bit);
                }
            }
            new_mask &= allowed;
        }

        if (new_mask != old_mask) {
            cell.candidate_mask = new_mask;
            cell.candidate_count = static_cast<u32>(__builtin_popcountll(new_mask));
            cell.entropy = static_cast<u8>(cell.candidate_count);
            ++changed;

            if (cell.candidate_count == 0) {
                out_contradiction = true;
            } else {
                propagator_.OnCellCollapsed(grid, c, cell.collapsed_tile, cell.collapsed_variant);
            }
        }
    }

    return changed;
}
```

```cpp
CGPointSet WFCOutput::ConsumeSteps(WFCStepBuffer& buf,
                                   const WFCTileRegistry& registry,
                                   f32 cell_size) {
    // Single-pass: drain into local vector, then build point set.
    utl::vector<WFCStep> steps;
    steps.resize(256);
    while (true) {
        u32 n = buf.Consume(steps.data() + steps.size() - 256, 256);
        if (n == 0) break;
        if (n < 256) {
            steps.resize(steps.size() - (256 - n));
            break;
        }
        steps.resize(steps.size() + 256);  // grow for next batch
    }

    CGPointSet result{};
    result.Init(static_cast<u32>(steps.size()), static_cast<u32>(PCGAttr::Count));

    for (u32 i = 0; i < steps.size(); ++i) {
        const WFCStep& s = steps[i];
        if (s.kind != WFCStepKind::Collapse) continue;

        // Find the index in the point set for this collapse (skip non-Collapse steps)
        // For Phase A.3 simplicity: assume all steps are Collapse (no Restart/Propagate).
        // Phase B will need to handle mixed step kinds.
        const WFCTile& tile = registry.Get(s.tile);
        result.positions[i] = math::v3{
            static_cast<f32>(s.coord.x) * cell_size,
            static_cast<f32>(s.coord.y) * cell_size,
            static_cast<f32>(s.coord.z) * cell_size
        };
        result.SetAttr(i, PCGAttr::ScaleX, 1.0f);
        result.SetAttr(i, PCGAttr::ScaleY, 1.0f);
        result.SetAttr(i, PCGAttr::ScaleZ, 1.0f);
        result.SetAttr(i, PCGAttr::RotationY, 0.0f);
        result.SetAttr(i, PCGAttr::MeshIndex, static_cast<f32>(static_cast<u32>(tile.mesh_handle)));
        result.SetAttr(i, PCGAttr::TechniqueIndex, 0.0f);
    }

    return result;
}
```
