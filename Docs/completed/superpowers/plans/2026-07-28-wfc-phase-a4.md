# WFC Phase A.4: Real-time Collapse Rendering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render the WFC-collapsed 4×4×4 grid as real geometry in a Metal-backed window so the user can see the solver's output visually — distinct tile types (cube, ramp×4rot, corner_in, corner_out, pillar) placed per cell.

**Architecture:** Bake-on-load: solver runs once at scene start, the resulting `PCGPointSet` feeds `PCGEntityFactory::CreateEntities`, entities are pushed into `StandardRenderPipeline::SetPCGEntities`, and the existing Forward renderer draws them every frame. Catalog tiles render via existing `create_box_mesh` for cube/corner/pillar and one new `create_ramp_mesh` generator for ramps (with per-variant `RotationY` producing the 4 rotations). The WFC catalog stays pure — placeholder mesh_handles (1000-1004) are overridden with real `ForwardSceneRenderer` slot indices after registration.

**Tech Stack:** C++17, primal engine (`StandardRenderPipeline`, `PCGEntityFactory`, `ProceduralMesh.h`, `ForwardSceneRenderer`), Metal RHI backend, Phase A.3 WFC foundation (`WFCTileCatalog`, `WFCSolver`, `WFCOutput`, `ParametricTileNode`).

**Spec reference:** `Docs/superpowers/notes/2026-07-28-wfc-phase-a3-completion.md` (Phase A.3 completion, known limitations)

**User-confirmed scope decisions (2026-07-28):**
1. **Bake on load** — solver runs once at scene start; no per-frame Step().
2. **One canonical ramp mesh + RotationY per variant** — lean 5-mesh catalog; PCGEntityFactory already honors RotationY.
3. **New TestWFCRendering.cpp** — clean isolation, Metal backend, no Sponza (empty scene + WFC grid).

```cpp
// --- Ramp (wedge) ---
// Generates a ramp mesh: a box where the +Z face slopes from full height (at -Z)
// down to slope_height (at +Z). Used by WFC catalog with RotationY to produce
// 4 rotations.
//
// Layout:
//   sx, sy, sz     : full extents (same as box)
//   slope_height   : height of the +Z end (0 = full ramp, sy = box)
//
// Topology: 8 vertices (4 base + 4 top) + 18 indices (5 quads = 10 tris, but
// slope end collapses to an edge so it's 5 visible faces).
inline id::id_type create_ramp_mesh(f32 sx, f32 sy, f32 sz, f32 slope_height) {
    // Clamp slope_height to [0, sy]
    if (slope_height < 0.0f) slope_height = 0.0f;
    if (slope_height > sy) slope_height = sy;

    // 8 corners: base (y=-hy) + top (y=+hy at -Z, y=+slope at +Z)
    const u32 vertCount = 8;
    const u32 idxCount = 30; // 5 quads * 2 tris * 3 idx = 30

    graphics::rhi::RHIMeshAsset asset;
    asset.num_vertices = vertCount;
    asset.num_indices = idxCount;
    asset.position_buffer.resize(vertCount * 12);
    asset.element_buffer.resize(vertCount * PROC_ELEM_STRIDE);
    asset.index_buffer.resize(idxCount * 4);

    u8* pos = asset.position_buffer.data();
    u8* elem = asset.element_buffer.data();
    const f32 hx = sx * 0.5f, hy = sy * 0.5f, hz = sz * 0.5f;
    const f32 top_slope = slope_height * 0.5f;  // top of slope end (in [-hy, +hy] space)

    // Bottom face vertices (y = -hy)
    // 0: -X, -Z     1: +X, -Z     2: +X, +Z     3: -X, +Z
    // Top vertices (y = +hy at -Z, y = top_slope at +Z)
    // 4: -X, -Z     5: +X, -Z     6: +X, +Z     7: -X, +Z
    WriteVertex(pos+ 0*12, elem+ 0*20, -hx, -hy, -hz,  0,-1, 0,  0, 0);
    WriteVertex(pos+ 1*12, elem+ 1*20,  hx, -hy, -hz,  0,-1, 0,  1, 0);
    WriteVertex(pos+ 2*12, elem+ 2*20,  hx, -hy,  hz,  0,-1, 0,  1, 1);
    WriteVertex(pos+ 3*12, elem+ 3*20, -hx, -hy,  hz,  0,-1, 0,  0, 1);

    WriteVertex(pos+ 4*12, elem+ 4*20, -hx,  hy, -hz,  0, 0,-1,  0, 0);
    WriteVertex(pos+ 5*12, elem+ 5*20,  hx,  hy, -hz,  0, 0,-1,  1, 0);
    WriteVertex(pos+ 6*12, elem+ 6*20,  hx, top_slope, hz,  0, 0, 1,  1, 1);
    WriteVertex(pos+ 7*12, elem+ 7*20, -hx, top_slope, hz,  0, 0, 1,  0, 1);

    u32* idx = reinterpret_cast<u32*>(asset.index_buffer.data());
    u32 ii = 0;

    // Bottom face (4 tris? No, 2 tris — quad 0-1-2-3)
    idx[ii++] = 0; idx[ii++] = 2; idx[ii++] = 1;
    idx[ii++] = 0; idx[ii++] = 3; idx[ii++] = 2;

    // -Z back face (quad 0-1-5-4)
    idx[ii++] = 0; idx[ii++] = 1; idx[ii++] = 5;
    idx[ii++] = 0; idx[ii++] = 5; idx[ii++] = 4;

    // +Z front face (collapses if slope_height > 0): quad 3-2-6-7
    //   but 2 and 6 share x=+hx, 3 and 7 share x=-hx; if slope > 0, this is a
    //   thin rectangle near the floor.
    idx[ii++] = 3; idx[ii++] = 6; idx[ii++] = 2;
    idx[ii++] = 3; idx[ii++] = 7; idx[ii++] = 6;

    // -X left face (quad 0-3-7-4)
    idx[ii++] = 0; idx[ii++] = 4; idx[ii++] = 7;
    idx[ii++] = 0; idx[ii++] = 7; idx[ii++] = 3;

    // +X right face (quad 1-2-6-5)
    idx[ii++] = 1; idx[ii++] = 2; idx[ii++] = 6;
    idx[ii++] = 1; idx[ii++] = 6; idx[ii++] = 5;

    // Slope top (quad 4-5-6-7) — the ramp surface. Visible from above.
    idx[ii++] = 4; idx[ii++] = 5; idx[ii++] = 6;
    idx[ii++] = 4; idx[ii++] = 6; idx[ii++] = 7;

    return RegisterProceduralMesh(asset);
}
```

**Note:** Vertex normals are approximate (the slope surface should ideally have a computed normal, but for Phase A.4 demo the per-face normals are visually fine — forward renderer applies simple Lambertian shading).

```cpp
bool WFCDemo::Initialize() {
    std::cout << "[TestWFCRendering] Initializing..." << std::endl;

    // 1. Window + Device + RenderSystem (Metal)
    platform::window_init_info winInfo{};
    winInfo.caption = "TestWFCRendering - WFC Phase A.4";
    winInfo.width = 1280;
    winInfo.height = 720;
    window = platform::create_window(&winInfo);
    if (!window.is_valid()) return false;

    rhi::DeviceDesc desc;
    desc.platform = rhi::RHIPlatform::Metal;
    desc.enableDebug = true;
    auto* metalDevice = new rhi::MetalDevice(desc);
    if (!metalDevice || !metalDevice->Initialize()) { delete metalDevice; return false; }
    device.reset(metalDevice);
    rhi::g_deviceManager.RegisterDevice(device.get());

    RenderSystemInitInfo sysInfo;
    sysInfo.device = device.get();
    sysInfo.window = window.handle();
    sysInfo.width = winInfo.width;
    sysInfo.height = winInfo.height;
    if (!renderSystem.Initialize(sysInfo)) return false;

    // 2. Pipeline
    pipeline = new StandardRenderPipeline();
    if (!pipeline->Initialize(device.get())) return false;
    pipeline->SetOutputResource(handles::INVALID_RESOURCE, {});
    pipeline->SetViewportSize(winInfo.width, winInfo.height);

    // 3. Empty scene + camera
    scene = std::make_shared<Scene>();
    camera = std::make_shared<Camera>();
    camera->set_position(math::v3{8.0f, 8.0f, 8.0f});
    camera->look_at(math::v3{0.0f, 0.0f, 0.0f});
    camera->set_perspective(60.0f, f32(winInfo.width) / f32(winInfo.height), 0.1f, 100.0f);

    std::cout << "[TestWFCRendering] Pipeline + scene ready" << std::endl;
    return true;
}

void WFCDemo::Run() {
    std::cout << "[TestWFCRendering] Running render loop (close window to exit)..." << std::endl;

    u32 frame = 0;
    while (window.is_valid()) {
        if (!platform::process_window_messages(window)) break;

        renderSystem.BeginFrame();

        auto* cmd = renderSystem.GetCurrentCommandBuffer();
        auto cmdHandle = renderSystem.GetCurrentCommandBufferHandle();
        u32 bufferIndex = renderSystem.GetCurrentFrameIndex();

        cmd->Reset();
        cmd->Begin();

        pipeline->RenderWithCommandBuffer(
            *scene, *camera, renderSystem.GetBackBuffer(),
            renderSystem.GetBackBufferDesc(),
            cmd, bufferIndex, cmdHandle, {});

        cmd->End();

        rhi::QueueSubmitInfo submitInfo{};
        submitInfo.cmdBuffer = cmdHandle;
        device->Submit(submitInfo);

        renderSystem.EndFrame();
        ++frame;

#if defined(HEADLESS_RUN)
        if (frame >= kHeadlessFrameCap) break;
#endif
    }

    std::cout << "[TestWFCRendering] Rendered " << frame << " frames" << std::endl;
}

    pipeline->ClearPCGEntities();

    if (pipeline) { pipeline->Shutdown(); delete pipeline; pipeline = nullptr; }
    renderSystem.Shutdown();
    if (window.is_valid()) platform::remove_window(window);
}
```

```cpp
// Registers 5 procedural meshes for the WFC catalog and captures their slot
// indices. The catalog tiles (cube=0, ramp=1, corner_in=2, corner_out=3, pillar=4)
// will be overridden to use these slots so WFCOutput writes correct MeshIndex attrs.
//
// Mesh choices:
//   cube        : create_box_mesh(1.0, 1.0, 1.0)        — 1×1×1 structural cube
//   ramp        : create_ramp_mesh(1.0, 1.0, 1.0, 0.0)  — full ramp (slope_height=0)
//   corner_in   : create_box_mesh(1.0, 1.0, 1.0)        — same geometry, scaled via attr
//   corner_out  : create_box_mesh(1.0, 1.0, 1.0)
//   pillar      : create_box_mesh(0.25, 2.0, 0.25)      — tall thin
//
// (Phase A.4 simplification: corners render as cubes. Phase B can give them
//  distinct L-shaped geometry.)
void RegisterWFCCatalogMeshes(WFCDemo& demo) {
    using namespace primal::content;

    auto cube_geo   = create_box_mesh(1.0f, 1.0f, 1.0f);
    auto ramp_geo   = create_ramp_mesh(1.0f, 1.0f, 1.0f, 0.0f);
    auto cornIn_geo = create_box_mesh(1.0f, 1.0f, 1.0f);
    auto cornOut_geo= create_box_mesh(1.0f, 1.0f, 1.0f);
    auto pillar_geo = create_box_mesh(0.25f, 2.0f, 0.25f);

    // Register all 5 via pipeline (no textures → fallback white)
    primal::id::id_type noTex[3] = {
        primal::id::invalid_id, primal::id::invalid_id, primal::id::invalid_id
    };
    demo.pipeline->RegisterMeshEntity(cube_geo,    noTex, 3);
    demo.pipeline->RegisterMeshEntity(ramp_geo,    noTex, 3);
    demo.pipeline->RegisterMeshEntity(cornIn_geo,  noTex, 3);
    demo.pipeline->RegisterMeshEntity(cornOut_geo, noTex, 3);
    demo.pipeline->RegisterMeshEntity(pillar_geo,  noTex, 3);

    // Capture slot indices from ForwardSceneRenderer
    auto* fwd = demo.pipeline->GetForwardRenderer();
    if (fwd) {
        const u32 meshCount = fwd->GetMeshInfoCount();
        demo.slot_cube       = meshCount - 5;
        demo.slot_ramp       = meshCount - 4;
        demo.slot_corner_in  = meshCount - 3;
        demo.slot_corner_out = meshCount - 2;
        demo.slot_pillar     = meshCount - 1;
    }

    std::cout << "[TestWFCRendering] Registered 5 catalog meshes: cube=" << demo.slot_cube
              << " ramp=" << demo.slot_ramp
              << " corner_in=" << demo.slot_corner_in
              << " corner_out=" << demo.slot_corner_out
              << " pillar=" << demo.slot_pillar << std::endl;
}
```

**Note:** ForwardSceneRenderer's slot indices are u32, but `WFCTile::mesh_handle` is `geometry::geometry_id` (typed u32). The override below casts through u32.

- [ ] **Step 3: Add `RunSolverAndEmit` helper**

Right after `RegisterWFCCatalogMeshes`, add:

```cpp
// Builds the WFC catalog (placeholder mesh_handles), overrides mesh_handles with
// real slot indices from RegisterWFCCatalogMeshes, runs the solver on 4x4x4,
// and drains Collapse steps into demo.wfc_point_set.
void RunSolverAndEmit(WFCDemo& demo) {
    WFCTileRegistry reg;
    TileAdjacencyTable adj;
    WFCTileCatalog::Populate(reg, adj);

    // Override placeholder mesh_handles (1000-1004) with real slot indices
    WFCTile& t_cube       = reg.GetMutable(wfc_tile_id{0});
    t_cube.mesh_handle    = geometry::geometry_id{demo.slot_cube};
    WFCTile& t_ramp       = reg.GetMutable(wfc_tile_id{1});
    t_ramp.mesh_handle    = geometry::geometry_id{demo.slot_ramp};
    WFCTile& t_corner_in  = reg.GetMutable(wfc_tile_id{2});
    t_corner_in.mesh_handle = geometry::geometry_id{demo.slot_corner_in};
    WFCTile& t_corner_out = reg.GetMutable(wfc_tile_id{3});
    t_corner_out.mesh_handle = geometry::geometry_id{demo.slot_corner_out};
    WFCTile& t_pillar     = reg.GetMutable(wfc_tile_id{4});
    t_pillar.mesh_handle  = geometry::geometry_id{demo.slot_pillar};

    // Configure solver
    WFCConfig config;
    config.grid_size = {4, 4, 4};
    config.max_cells_per_frame = 256;
    config.max_ms_per_frame = 1000;
    config.seed = 7;
    config.max_generations = 8;

    WaveGrid grid;
    grid.Initialize(config.grid_size, 8);

    WFCStepBuffer buf;
    WFCSolver solver;
    solver.Initialize(config, grid, reg, adj, buf);

    WFCSolveBudget budget(config.max_cells_per_frame, config.max_ms_per_frame);
    budget.Reset();
    WFCSolver::StepResult result = WFCSolver::StepResult::InProgress;
    u32 steps = 0;
    while (result == WFCSolver::StepResult::InProgress && steps < 1000) {
        result = solver.Step(budget);
        ++steps;
    }

    if (result != WFCSolver::StepResult::Done &&
        result != WFCSolver::StepResult::GivenUp) {
        std::cerr << "[TestWFCRendering] Solver did not terminate cleanly: "
                  << static_cast<u32>(result) << std::endl;
    }

    // Drain Collapse steps into a PCGPointSet (cell_size = 1.0 for tile-sized cells)
    demo.wfc_point_set = WFCOutput::ConsumeSteps(buf, reg, 1.0f);

    std::cout << "[TestWFCRendering] Solver emitted " << demo.wfc_point_set.count
              << " tile instances" << std::endl;
}
```
