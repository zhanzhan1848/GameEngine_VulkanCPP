# Sponza 天空档对比——室内/中庭间接光对比度（WRC 路径）

日期：2026-09-19 ｜ 配置：`PRIMAL_WRC_ENABLE=1`、frame 360 锁机位、2560×1440

## 背景

用户对照 Unreal Lumen 参考（暖阳、中庭亮/室内暗、红毯色彩弹射）指出：
间接光很平、无室内与中庭亮度区分。量化（GILadder 4240 室内 ROI 像素）：

| 配置 | 室内间接均值 | 说明 |
|---|---|---|
| 天空档 0.4（默认） | 0.506 | 阴影区被中性天空填充抬平——"平"的元凶 |
| 天空档 0.25 + Fusion gain 1.6 | 0.102 | 对比结构恢复，保留部分反弹补底（推荐档） |
| 天空档 0.15 | 0.040 | 对比最强但室内近黑——反弹补底不足暴露 |

**关键发现**：室内间接光 ~92% 来自逃逸射线的中性天空契约，几何反弹
（阳光→亮面→反弹）仅 ~0.04——探针在室内采到的是天空泄漏而非反弹。
这是比档位更深的传输问题（DDGI 命中率 / SC 室内视线覆盖专项）。

## 旋钮

- `PRIMAL_GI_SKY_INTENSITY`（默认 0.4）：GIDebug 天空档，DDGI/Gather 链
- `PRIMAL_WRC_SKY_TIER`（默认 0.4）：WRC 逃逸契约档
- `PRIMAL_GI_INDIRECT_GAIN`（默认 1.0）：Fusion 全链间接增益

## 追加（同日）：卡片→探针直投影（反弹修复）

WRC trace 的 SC 命中产出率实测仅 ~20%（漏斗仪表），几何反弹≈0。新增
`WRCCardInject`（DDGI SCDDGIIntegration 的 WRC 域等价边）：每探针按 CPU
邻域表（374 卡片，1935/1936 探针有卡）将卡片平均 radiance 以距离衰减权重
（≤0.45 封顶）注入最近方向槽。近场探针 meanLum 0.329→0.421（+28%）。

- `sky025_inject_on.png`——天空档 0.25 + gain 1.6 + 注入开（当前推荐档）
- 回滚：`PRIMAL_WRC_CARD_INJECT=0`
- 已知限制：无可见性检查（与 DDGI path B 同款），隔墙注入靠距离衰减限制

## 追加（同日 v3）：bootstrap 默认翻转 + 注入默认关（证据驱动）

实测对比度阶梯（lit/shadow ROI 亮度比，frame 360 锁机位）：

| 配置 | lit | shadow | 对比比 |
|---|---|---|---|
| 天空0.4 无注入 3m bootstrap关（原始） | 148.7 | 55.1 | 2.7× |
| 天空0.25 gain1.6 无注入 3m bootstrap关 | 132.3 | 19.4 | 6.8× |
| +卡片注入 v1（cap0.6 半径7m） | 158.0 | 71.2 | **2.2×（洗平）** |
| 注入 v2（可见性收紧+2m） | 158.0 | 71.3 | 2.2× |
| **bootstrap 开 + 注入关** | **129.6** | **17.0** | **7.6×（最佳）** |
| bootstrap 开 + 注入 top-1 cap0.3 | 151.5 | 49.7 | 3.0× |

结论：①馈送常开回路（bootstrap 关）把天空能量循环放大——室内间接 0.49
vs 物理期望 0.11，是"平"的第一成因 → **bootstrap 默认翻 1**；
②卡片注入逐帧累加（16 卡×0.3 → trace 值剩 0.7^16）洗平对比度 →
**注入默认关**（PRIMAL_WRC_CARD_INJECT=1 供 v4 重设计 A/B：权重归一 +
可见性强化 + 多卡能量守恒混合）。

  翻转+全修复），对比比 7.6×、2551 帧 0 validation。
