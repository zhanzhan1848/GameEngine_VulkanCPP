## 最终目标

本地/远端数据通过可扩展连接器驱动属性，时间、质量、断线与诊断清楚；无需特定业务后端才能用。

## 当前基础与广度/深度差距

未确认完整设备数据生产链；CLI/MCP 工具通信不是设备时序数据管线。

| 维度 | 需要补齐的方向 |
|---|---|
| 广度 | 文件/模拟源和按需 HTTP/MQTT/OPC UA 等适配、字段映射与数据质量。 |
| 深度 | 时间戳、乱序/重复、断线恢复、背压、批量更新和异常输入；凭据处理。 |

此表是规划差距，不是本轮运行审计。立项时把已有/部分/未支持状态绑定到代码、专项文档和真实操作结果，避免重复实现或误报完成。

## 本模块阶段与验收

| 阶段 | 交付范围 | 代码与数据验收 | 交互、成本与视觉验收 |
|---|---|---|---|
| S1 数据源与映射 | 模拟/文件源、字段选择、单位转换、质量状态 | 参考序列、类型/单位、缺值、坏数据、重载 | 连接→选字段→绑定→预览不超过 8 次操作；无需修改引擎，未知/过期可见 |

| S3 连接器扩展 | 多源/版本、时间策略、记录与回放输出 | 不同时间域、批量数据、一致映射、连接器升级 | 新源复用映射 UI；同一模板适配不同设备；字段变化能定位并修复 |

## 真实交互与最终效果验收

用确定时序夹具先验证再接真实源；断线/乱序后比较最终属性与记录，检查状态灯和数值是否误导。

至少三名未参与实现者依靠内置提示/正常帮助完成基础场景及一次失败恢复，保留操作录像、结果截图/视频、期望数据、操作数、耗时、求助与返工。作者演示不能替代该项。首次环境配置和每次制作成本分别记录；基础任务不要求重编引擎、手修场景文件或复制内部 ID。

UI 按实际支持平台检查 100%/150%/200% 缩放、最低窗口尺寸、长名称/中文、空/加载/错误/禁用状态与键盘焦点。最终效果检查真实内容或实测结果，不只检查面板排版。数值/图像误差、延迟/内存与交互预算在实施前按代表机器和夹具冻结；没有数字预算的项目须补全后才验收。

## 详细设计与接口契约

> 本节是拟议实施合同，尚未实现。类名/记录名/API 操作是概念命名；实施时对齐现有 Registry、ABI 与文档 schema，不表示这些命令已经可调用。严格关口和量化规则见 [阶段验收合同](stage-acceptance-contract.md)，结果使用 [验收模板](acceptance-record-template.md)。

| 设计项 | 本模块约定 |
|---|---|
| 数据模型 | `DataSource/ChannelSchema/Sample/Binding`；业务身份稳定，不以原生地址/数组位置作持久引用 |
| 字段/版本 | sourceId、deviceId/fieldId、type/unit、source/receiveTime、quality/sequence、queuePolicy、authRef；持久文档带 schemaVersion，派生记录 inputHash/toolVersion |
| 接口/执行 | connect/read/subscribe/map/disconnect；读数据默认，映射通过属性适配，不裸写EngineDLL |
| 数据/运行路径 | 模拟/文件源→规范化采样→时序策略/背压→绑定→事件/记录→Player |
| 失败/恢复 | 乱序/重复策略固定；断线quality=stale；凭据不进项目明文/日志；过量按policy记录丢弃 |
| 修改归属 | 沿源码复核表中既有核心/适配器/文档/编辑入口扩展；领域服务与数据独立，UI/CLI 共用，编辑写入走文档/Undo，运行写入走唯一宿主 |
| 保存/迁移 | 原件与已验证产物保留；临时文件校验后提交；迁移记录字段/身份映射、丢失项、备份与恢复；未知版本不静默覆写 |
| 线程/事件/取消 | 主线程编辑事务，后台重计算/外部进程；结果带 generation/版本以拒绝晚到回调；关闭释放订阅/资源，远端取消能力分别声明 |
| 扩展成本 | 新节点/格式/适配器通过注册；不能为样例改核心或复制另一套UI/CLI；依赖只要求本阶段所需能力 |

## 不做项目与范围边界

设备指令闭环控制（不纳入默认只读）；一次实现所有协议（不要求）；CLI/MCP冒充设备协议（不采用）

延后/暂缓与非目标沿用总规划中的用户决定；其他可选/外部优先/建议边界是本模块规划方案，不能冒充用户确认的永久排除。外部负责仍需接入、数据交换和真实验收。

| 阶段 | 明确不做 | 仍需保留 |
|---|---|---|
| S1 | 一种在线协议；重连/队列；诊断 与 连接器注册/版本；多源时间；记录输出 不在基础阶段建设 | 可靠手工闭环、失败诊断、保存/交付 |
| S2 | 连接器注册/版本；多源时间；记录输出 不提前成为验收前置 | S1通过能力/兼容，不因深度改造破坏已有结果 |
| S3 | 未选入支持清单的专项/软件/格式/设备/协议 | 扩展契约、两个用途/来源样例和承诺组合逐项实测 |
