## 最终目标

地形编辑、纹理绘制、植被散布和道路/水体接口能组成常见环境，预览、保存、流送与运行一致。

## 当前基础与广度/深度差距

已核对 TerrainSDF、PCG SurfaceNets 与 StreamingMesh 接口；这是程序化/体素网格基础，未确认完整地形资产、笔刷与植被制作链。

| 维度 | 需要补齐的方向 |
|---|---|
| 广度 | 雕刻/绘制/植被笔刷、道路/水体、导入高度与环境预设。 |
| 深度 | 编辑与流送数据同步、接缝、LOD/风/碰撞、实例预算与撤销。 |

此表是规划差距，不是本轮运行审计。立项时把已有/部分/未支持状态绑定到代码、专项文档和真实操作结果，避免重复实现或误报完成。

## 本模块阶段与验收

| 阶段 | 交付范围 | 代码与数据验收 | 交互、成本与视觉验收 |
|---|---|---|---|

## 真实交互与最终效果验收

小山坡、道路旁植被、水边环境；走近走远并跨块修改、撤销、保存、重开。测编辑到反馈、返工和接缝。

至少三名未参与实现者依靠内置提示/正常帮助完成基础场景及一次失败恢复，保留操作录像、结果截图/视频、期望数据、操作数、耗时、求助与返工。作者演示不能替代该项。首次环境配置和每次制作成本分别记录；基础任务不要求重编引擎、手修场景文件或复制内部 ID。

UI 按实际支持平台检查 100%/150%/200% 缩放、最低窗口尺寸、长名称/中文、空/加载/错误/禁用状态与键盘焦点。最终效果检查真实内容或实测结果，不只检查面板排版。数值/图像误差、延迟/内存与交互预算在实施前按代表机器和夹具冻结；没有数字预算的项目须补全后才验收。

## 依赖与分工

地形内容制作与大世界加载分工；PCG 可作为生成来源，不替代手工编辑入口。

可用本地夹具完成基础验收；自动化与 Agent 为可选入口，UI/CLI 必须复用同一数据与命令契约。新增适配器的安装、许可/账号、版本和验证状态由 [集成中心](software-integrations-and-skills.md) 展示；长任务可接 [任务与产物](agent-workflows-and-artifacts.md)。

## 详细设计与接口契约

> 本节是拟议实施合同，尚未实现。类名/记录名/API 操作是概念命名；实施时对齐现有 Registry、ABI 与文档 schema，不表示这些命令已经可调用。严格关口和量化规则见 [阶段验收合同](stage-acceptance-contract.md)，结果使用 [验收模板](acceptance-record-template.md)。

| 设计项 | 本模块约定 |
|---|---|
| 数据模型 | `TerrainAsset/TileEdit/VegetationLayer`；业务身份稳定，不以原生地址/数组位置作持久引用 |
| 字段/版本 | 路线heightfield或voxel、unit/tileCoord/resolution、编辑delta、surface/植被refs、seed/LOD策略；持久文档带 schemaVersion，派生记录 inputHash/toolVersion |
| 接口/执行 | brush/applyUndo/rebuildTile/scatter；源编辑与GPU派生分开，ID稳定 |
| 数据/运行路径 | 先选择路线→资产/笔刷→派生→保存→流送；复用PCG/StreamingMesh而非视为已完整 |
| 失败/恢复 | 坏高度/块缺失提示；后台烘焙取消保留旧派生；笔刷事务跨块原子或明确分组 |
| 修改归属 | 沿源码复核表中既有核心/适配器/文档/编辑入口扩展；领域服务与数据独立，UI/CLI 共用，编辑写入走文档/Undo，运行写入走唯一宿主 |
| 保存/迁移 | 原件与已验证产物保留；临时文件校验后提交；迁移记录字段/身份映射、丢失项、备份与恢复；未知版本不静默覆写 |
| 线程/事件/取消 | 主线程编辑事务，后台重计算/外部进程；结果带 generation/版本以拒绝晚到回调；关闭释放订阅/资源，远端取消能力分别声明 |
| 扩展成本 | 新节点/格式/适配器通过注册；不能为样例改核心或复制另一套UI/CLI；依赖只要求本阶段所需能力 |

## 不做项目与范围边界

同时维护两种地形路线（可选）；新植被/地形着色LOD优化（延后）；GIS地图业务（独立）

延后/暂缓与非目标沿用总规划中的用户决定；其他可选/外部优先/建议边界是本模块规划方案，不能冒充用户确认的永久排除。外部负责仍需接入、数据交换和真实验收。

| 阶段 | 明确不做 | 仍需保留 |
|---|---|---|
| S1 | 植被层/密度排除；实例身份；风/碰撞现有接口 与 分块/局部烘焙；道路水体接口；大世界联动 不在基础阶段建设 | 可靠手工闭环、失败诊断、保存/交付 |
