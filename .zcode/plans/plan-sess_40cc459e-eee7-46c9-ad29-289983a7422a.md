# GI 层级化融合重构（Surface Cache → DDGI → SPGI → 最终着色）+ DDGI 3阶SH一致化 + SPGI 实效评估

## 背景结论（探索阶段已确认）

- **SPGI 在 Vulkan 后端从未跑对过**：`ScreenProbeGIPass.cpp` 的 Place(~1205)/Gather(~1565) 子通道仍按 Metal 槽位写描述符，与 shader 的平铺布局冲突（SSBO 覆盖图像槽、UBO 槽号错位）。此前所有 SPGI 评估都在 Metal 上。
- 现有融合是**逐像素三路平铺加权**，不是层级兜底；DDGI 的 SC→Probe 路径只写 L0+L1 且仅在 probe 首次更新前一帧生效（置信度二值化）；多个消费者只读 4/9 个 SH 系数；legacy gather 路径 SH 基符号与投影基不匹配。
- 无硬件 RT 基础设施（无 VK_KHR_ray_tracing），方案中 tracing = 屏幕 HZB + SDF，HW RT 留作未来扩展。

## Phase 0 — 阻断性修复（SPGI 可评估的先决条件）

1. **SPGI Vulkan 绑定修复**（`Engine/Graphics/Lumen/ScreenProbes/ScreenProbeGIPass.cpp`）：Place 的 SSBO→binding 2/3、UBO→4；Gather 的 positions→3、SH→4、UBO→5、normals→6（对齐 shader 平铺声明，参照已转换的 Trace/Average/Temporal 模式，含 SetComputeBytes 槽位）。
2. **`DDGIGIGather.comp`**：`vec4 nvolSh9[9]` → `nvolSh9[]`（修形式越界）；legacy near(:772)/far(:683) SH 求值基改为与 `DDGIUpdateIrradiance.comp:177-186` 投影基一致的规范基。重编 spv。
3. **三缓冲槽位统一**：`BuildRenderGraph` 的 SCDDGI 调用补 `frame_index`（`StandardRenderPipeline.cpp:1480`）；审计 GIGather `(cbIdx+2)%3` 与写者 `frameCount%3` 的相位差，统一为单一约定。
4. **probe_vis Confidence 索引修复**（`DDGIGIGather.comp:388` `confidenceBuffer[pIdx]` → `[pIdx*4+3]`）。

1. `TestVulkanSponzaRenderGraph.cpp`（:404 预设 Medium→High，SPGI 开启），构建 `Darwin/Debug/TestVulkanSponzaRenderGraph` 并运行——第 60/61 帧自动截屏到 `/tmp/sponza_jit_on_60/61.ppm`。

3. 输出实效评估报告（探针密度、L0+L1 角分辨率上限、置信度塌陷区、接缝、噪声），结论用于校准 Phase 3 的融合权重。

## Phase 2 — DDGI 全链路 3 阶 SH（9 系数，L0-L2）一致化

1. **SC→Probe 投影升满 9 系数**：`SCDDGIIntegrationModule.cpp` `BuildCardProbeAssignment` 的 sh_weights 从 4 项扩到 9 项（补 L2 基，符号对齐规范基）；`DDGIProbeIrradianceFromCards.comp` 写入 0..8 全带。
2. **卡片辐照度真实面积采样**：`DDGICardRadianceAvg.comp` 从中心单 texel 改为 4×4 覆盖加权采样（用 albedo alpha 有效性做权重）。
3. **消费者读满 9 系数**：`ScreenProbeTraceFinalize.comp` DDGI 回落 evalSH9；`DDGITraceFinalize.comp` `samplePrevProbeGrid` 多反弹项读 9。
4. **SPGI 的 DDGI 回落升级**：最近单 probe → 8-probe 三线性 + 法线权重（近 volume 附带深度 Chebyshev，移植 gather 逻辑）。

## Phase 3 — 层级化融合（用户已选定：SSGI 降级为高频细节层）

1. **DDGI 数据源反转（SC-first）**：SCDDGI 从"二值 bootstrap"改为持续主收集器——`mix(traceResult, scResult, scCoverage)`，scCoverage 由卡片指派覆盖度/图集有效性驱动；SDF trace 降为覆盖不足时的补充。置信度缓冲改为真实收敛爬坡（更新计数）。统一 TemporalAlpha / ProbeHysteresis 两个时间常数。
2. **SPGI TraceFinalize 辐射源层级**：SDF 命中 → SC 光照图集为主（放开 2 世界单位限制）；HZB 屏幕命中 → 前帧屏幕色（不变）；miss → 升级后的 DDGI 回落。SC 来源的辐照度去掉与图集反馈重复的 `albedo*L_i_prev` 多反弹项（避免双重反弹）。
3. **FusionIndirect 层级公式**：
```glsl
float spgi_w = clamp(spgi4.a * 2.0, 0.0, 0.9);              // 封顶，DDGI 保底
vec3 gi = spgi4.rgb * spgi_w                                 // 主力：屏幕探针
        + ddgi * (1.0 - spgi_w)                              // 兜底：世界探针(SC喂)
        + ssgi_irr * ssgi_conf * 0.15 * mix(0.3, 1.0, spgi_w); // 细节层
indirect = albedo * gi * ao;
```
   SPGI 关闭档位保持现有 DDGI+SSGI 公式（`#ifndef`/uniform 分支）。
4. **置信度重设计**（`ScreenProbeAverage.comp`）：`confidence = hitRatio * mix(0.4, 1.0, exp(-4*variance))`，高对比区不再塌陷为 0。
5. **融合门条件修复**：仅 SPGI 开（SSGI/SSR 关）时融合 pass 也要执行（`StandardRenderPipeline.cpp:1635/2382` 条件加 `enable_screen_probes`）。
6. 两条管线路径（BuildRenderGraph 与 RenderWithCommandBuffer）同步修改。
