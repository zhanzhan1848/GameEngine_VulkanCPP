# T8.12 卡视角捕获立项 — 实施计划

## 目标
用真·卡视角正交渲染替换 Surface Cache 的屏幕空间重投影捕获，解除相机绑定——让探针拿到全场景（含离屏/遮挡/背面）的 albedo×光照，使彩色反弹可见、红框区欠亮修复。

## 已确认的复用资产（侦察结论）
- `ExecuteReflectionPass`（GPUDrivenDrawPipeline.cpp:3820-3996）：任意 VP + CPU meshlet 剔除 + 自建 indirect args 的完整骨架，照抄改造
- `PipelineDraw.vert/.frag`：全局几何 buffer（vertex/element/instance/cluster）+ 材质纹理数组采样（binding 9-13）全部现成
- `CreateAtlasTextures` 已有 `renderTarget` 形参位；atlas 全局 buffer 布局与 `worldToCardUV` 深度语义保持
- PlanarReflection 模式：模块自持 RT + `SideEffect()` + 裸 RenderPassDesc（atlas 不走 RG 跟踪，手动 barrier）
- 灰色反弹来源已实锤：AtlasInit 首帧用默认材质播种全图集（alpha=1），未捕获 texel 被 LightEval 当灰材质点亮——新路径逐 texel 替换之

## 阶段 0 · 地基（小）
1. `CreateAtlasTextures`：albedo/normal/depth 三 atlas 打开 renderTarget（orm 占位第四 RT）
2. 新增 transient 深度附件（D32_Float、atlas 尺寸、DepthStencil usage，**不加** RenderTarget——Vulkan VUID 红线，照 GPUDrivenDrawPipeline.cpp:468-481 样板）
3. 批次调度器：`SC_CARDVIEW_CARDS`（默认 8）张卡/帧轮换；seed 模式 32 张/帧直到 407 卡全覆盖（~13 帧），之后稳态 8 张/帧（全量刷新 ~50 帧 ≈ 1s）

## 阶段 1 · 卡视角绘制管线（主体）
1. 新 shader `CardCapture.vert/.frag`：vert = PipelineDraw 语义 + push-constant 正交 VP；frag = PipelineDraw 材质采样 + 三处改动（normal→oct-encode rgba8、albedo.a=1、新增 R32F 输出 axisDepth——语义对齐 worldToCardUV）
2. SurfaceCachePass 新增 graphics 管线：4 RT [rgba8, rgba8, r32f, rgba8 占位] + D32；layout 克隆 draw_pipeline_ 的全局 buffer 绑定 + push constant range
3. `ExecuteCardCapturePass`（克隆 ExecuteReflectionPass）：CPU AABB∩card-box meshlet 剔除 → 自建 indirect args → `SetViewport(atlas_offset, resolution)` → DrawIndirect
4. 每帧批次：每卡取 CardGenerator 已分配的非退化面（沿用 5% 筛选），每面一个 BeginRenderPass（MRT load=Load、depth clear）
5. RG 集成照 PlanarReflection 模式；与屏幕空间 capture 按 env 互斥执行

## 阶段 2 · 验证（工具链全复用）
1. atlas 回读自检（CopyImageToBuffer，照 OFFLINE_SDF_VERIFY 模式）：banner 卡 albedo ≈ 红/绿色、alpha=1
2. `DDGI_RECT` RGB 窗口复测：红布旁石头 R−G ≥ +0.03（当前 +0.01）、五窗口蓝偏移收窄
3. 三区读数多运行中位 ≥3 跑：L_2F/OUTER 不回归（±1 内）；REDBOX 预期抬升
4. 红框区/左旗区目检 + 全帧 clip%

## 阶段 3 · 收口
- env 门控 `SC_CARDVIEW=1`（默认关起步，验证通过后翻默认）；屏幕空间路径保留为回退
- 文档 T8.12 立项→收口行；REDBOX 若仍欠亮则接续 T8.11 其余项

## 风险与对策
- PipelineDraw 的 meshlet 间接索引语义：照抄 ExecuteReflectionPass 的 cpu_meshlet_cache_ 用法（已验证可跑）
- 双面薄板 z-fighting：正交投影 + CullMode::None + less-equal
- 性能：8 卡 × ≤3 面，CPU 剔除后每面 ~10-40 draw；meshlet_cache 扫描 ~20 万次/帧，可接受
- 写冲突：卡视角批与屏幕空间 gather 互斥执行（env 分支）

## 验收标准
阶段 2 三条全绿 + 目检左旗区/红框区出现彩色反弹（布料颜色染到邻近石头）。
