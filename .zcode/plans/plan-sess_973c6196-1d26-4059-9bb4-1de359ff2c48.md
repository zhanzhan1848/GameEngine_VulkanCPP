### Segment.h 核心数据结构

```cpp
namespace primal::tools::segment {

// 形状分类
enum class ShapeClass : u8 {
    Compact,     // 球状/块状（刀首、底座）
    Elongated,   // 细长杆状（刀刃、刀柄、柱身）
    Flat,        // 扁平片状（护手、桌面）
    Intermediate // 不规则
};

// 部件模板槽位
struct PartSlot {
    std::string     name;                 // "blade"
    ShapeClass      shape{ShapeClass::Intermediate};
    f32             volume_ratio_min{0};  // 占总体积比例范围
    f32             volume_ratio_max{1};
    f32             axis_pos_min{-1};     // 在主轴上的归一化位置 [-1,+1]
    f32             axis_pos_max{1};
};

// 部件模板
struct Template {
    std::string             name;         // "sword"
    utl::vector<PartSlot>   slots;
};

// 单个分割出的部件描述
struct Part {
    u32             component_id;
    std::string     matched_slot;         // 匹配到的模板槽位名
    ShapeClass      shape_class;
    math::v3        centroid;
    math::v3        principal_axis;
    f32             eigenvalues[3];       // λ_min, λ_mid, λ_max
    f32             elongation;           // 1 - λ_mid/λ_max
    f32             flatness;             // 1 - λ_min/λ_mid
    f32             volume;
    f32             volume_ratio;         // /total
    f32             axis_position;        // [-1,+1]
    u32             face_count;
    u32             vertex_count;
};

// 分割结果
struct Result {
    utl::vector<u32>   face_labels;       // per-face component id
    utl::vector<Part>  parts;             // 部件描述
    std::string        matched_template;  // 匹配到的模板名
};

struct Params {
    // 分割模式
    enum class Mode : u8 {
        ConnectedComponents = 0,  // igl::facet_components
        FeatureBased        = 1,  // dihedral-gated flood-fill
    } mode{Mode::ConnectedComponents};

    f32                     dihedral_threshold_deg{60.f};
    utl::vector<Template>   templates;     // 空则只做部件发现不做匹配
};

Result Run(const ProcessableMesh& in, const Params& params,
           utl::vector<ErrorReport>& errors);

}  // namespace
```

### Segment.cpp 实现步骤

**Step 1: 部件发现**
- Mode=ConnectedComponents: 构建 Eigen::MatrixXi F，调用 `igl::facet_components(F, C)` 得到 per-face component id
- Mode=FeatureBased: 构建 PMP SurfaceMesh，flood-fill 按 dihedral angle > threshold 分割

**Step 2: Per-part 几何描述**（对每个 component）
- 收集 component 的所有顶点位置
- Eigen PCA: `SelfAdjointEigenSolver<Matrix3d>` 算主轴 + 特征值
- 形状分类: elongation/flatness 比值
- 体积: divergence theorem 求和
- 体积比例: part_volume / total_volume
- 轴位置: centroid 在全 mesh 主轴上的投影，归一化到 [-1,+1]

**Step 3: 模板匹配**（如果 templates 非空）
- 对全 mesh 做 PCA 得到主轴方向
- 各 part 按 axis_position 排序
- 贪心匹配: 对每个 (part, slot) 计算匹配分数（shape class + volume ratio + position）
- Hungarian/greedy assignment 最大化总分

**Step 4: 输出**
- `face_labels`: per-face component id
- `parts`: 部件描述列表
- `matched_template`: 匹配到的模板名
