## 方案：将离线高精度 SDF 接入 DDGI Tracer

### 核心思路
DDGI tracer 当前从 `GlobalSDF::Get()` 的 3 个运行时 cascade 获取 SDF 数据。我们将增加一个"离线 SDF 数据源"模式——当启用时，DDGI 用 OfflineSDFMerger 生成的 384³ 全局 SDF volume 替代运行时 cascade。

### 数据流变更
```
当前：GlobalSDF cascade (R32Float, 80³, voxel=1.0m) → DDGI binding 0/1/2
新增：OfflineSDFMerger (R16F, 384³, voxel=0.089m) → DDGI binding 0（cascade count=1）
```

### 实现步骤

#### 1. 修改 `LumenDDGIPass.h`
- 添加离线 SDF 数据源成员：`ResourceHandle offline_sdf_texture_`, `v3 offline_origin_`, `v3 offline_extent_`, `u32 offline_resolution_`, `bool has_offline_sdf_`
- 添加 setter：`SetOfflineSDFSource(texture, origin, extent, resolution)`

#### 2. 修改 `LumenDDGIPass.cpp` — AddPass execute lambda
- SDF texture 解析（~line 1117）：当 `has_offline_sdf_` 时，`sdfTextures[0] = offline_sdf_texture_`，cascade 1/2 = INVALID，`sdfAvailable = true`
- UBO 填充（~line 1315）：当 `has_offline_sdf_` 时，`SdfOrigins[0] = offline_origin_`，`SdfExtents[0] = offline_extent_`，`SdfVoxelSizes[0] = offline_voxel_size`，`SdfResolutions[0] = offline_resolution_`，`SdfCascadeCount = 1`

#### 3. 修改 DDGI shader 的 traceSDF
DDGI 的 `traceSDF`（DDGITraceRays.comp line 209-276）用 sphere tracing：`t += minDist`，`minDist < voxelSize * 0.5` 时命中。但离线 SDF 是 **unsigned distance**——sphere tracing 会越过表面。

修改：在 cascade count=1 且 SDF 是 unsigned 时，改用 **adaptive first-hit march**：
- `t += min(d * 0.9, voxelSize * 4)`（自适应步进）
- `d < voxelSize * 0.75` 时命中
- 这和 OfflineSDFViz.comp 中验证过的逻辑一致

**关键**：不能修改 WGSL shader（用户要求）。DDGITraceRays.comp 是 GLSL shader——可以修改。

#### 4. 修改 `StandardRenderPipeline.h/cpp`
- 添加 `SetOfflineSDFSource` 转发给 DDGI pass（类似已有的 SDF 可视化 setter）
- 在 test 中调用

#### 5. 修改 `TestVulkanSponzaRenderGraph.cpp`
- 将 OfflineSDFMerger 的 texture 同时传给 SDF 可视化和 DDGI

### UBO 布局兼容性
DDGI 的 `SdfResolutionsAndCount` 是 `uvec4`（offset 256）——C++ 中 `SdfResolutions[3]` + `SdfCascadeCount`。离线模式下 `SdfResolutions[0] = 384`, `SdfCascadeCount = 1`，其他保持 0。shader 中 `sdfCascadeCount()` 读 `.w` = 1，只遍历 cascade 0。

### 不改的部分
- GlobalSDF 运行时体素化仍正常运行（可视化用）
- DDGI 的 probe grid / irradiance / 历史缓冲逻辑不变
- 只替换 SDF trace 的数据源和 trace 算法
