# 把硬编码太阳光移入场景 + HDR 环境 + 多光源渲染

工作分支：`feat/avalonia-migration`（worktree `.worktrees/avalonia-migration`）。

## 目标
1. 新建场景时自动创建一个"太阳"方向光实体（位置 (100,150,50)，光色等效 {20,20,20,1.0}，即 Color(1,1,1)×Intensity 20——视觉与现在硬编码完全一致，因为现 shader 丢弃 alpha，需在填充端改为 color×intensity 相乘）。
2. 场景环境支持 HDR（.hdr equirect）：作为可见天空盒 + 烘焙 IBL 提供环境光（你已确认范围）。
3. 视口渲染消费场景内**所有**灯光（方向光≤4 + 点光/聚光≤128）；阴影仅太阳光（保持现有 2 级级联）。
4. 接通 Inspector 实时改灯光参数（C++ setter 已导出，C# 缺 DllImport 与调用）。
