# engine_rc_review：RC 实验复用记录

日期：2026-10-29。职责：仅审查/修正独立 RC GLSL；不改生产 Engine 文件，不运行主场景 GPU，不与主代理构建竞争。

这是子代理可复用的项目经验记录，不代表模型参数训练或自动能力提升。只有明确给出证据与范围的结论可用于后续任务。

## 已验证的契约

- 区间保存 `(radiance.rgb, transmittance)`；`w=-1` 表示未知、`w=0` 表示已知遮挡（含合法黑）、`w=1` 表示该有限区间已知通畅。近段已遮挡时不读取远段，避免未知远场覆盖合法黑。
- 相邻级方向使用等立体角 `(azimuth, y)` 网格，每方向被更高一级四个子方向分割。独立 CPU 检查验证 side=4 与 side=8 的四子映射分别无重复、无遗漏；只是分区契约，不认证插值画质或 GPU 等价。
- `1000m` 有限区间 miss 不自动认证天空。最远级仅在根场景 AABB 后续不再相交时允许天空；否则标未知。该保守界可能增加未知，但不将有限距离 clear 冒充全场 escape。
- 所有实际参与空间插值的 tap 都要已知；零权重 tap 不影响资格。缺失 tap 不重归一化成完整覆盖。
- RC 当前没有灯光/几何纪元的持久缓存资格。未进入本帧更新区的探针在 trace/merge 各自写为未知，避免把旧灯光当作当前有效数据。它是视锥驱动更新原型，尚非持久滚动世界缓存。
- 深度、法线、齐次除法、世界位置、atlas尺寸、card边界、UV 和辐射值需要有限数检查；无效输入输出零覆盖，不能形成 NaN 传播或整数转换异常。
- Surface Cache 候选要求同 owner、capture-facing、完整 atlas 矩形、同尺寸 lighting/depth、有效 alpha/depth、完整点距≤0.05m、card轴向平面误差≤0.002m。合法黑保留。

## 尚未闭合，禁止升级为正式结论

1. **SC 源资格不完整**：没有绑定/核验 primitive identity 或真实几何法线。owner + 距离 + card-plane 仍可能混合近邻三角形或异面，不能把该查询写为生产级 surface certificate。页表物理重映射亦未接入，不能对启用页表路径宣称同源。
2. **空间插值可见性**：没有接收点到探针/各 probe 之间的完整连接验证，薄墙、接缝、近场和多层几何可能漏光；当前 RC 的主要画质实验风险就在这里。
3. **同原点区间近似**：更粗探针的远段插值不等于从当前细探针真正追踪的远段，尤其是高视差几何。未实现额外的 parallax/bilinear fix。
4. **最远源与多反弹**：constant DDGI sky + 当前 SC radiance，不是独立的 RC 多反弹求解；SC 可能已经包含现有 GI。性能只包含 RC 传输，不能据此宣称整套 GI 替代帧率。
5. **格域与边界**：所有级联总世界域相同，粗级有效插值内域更小；外扩视锥不能扩大该世界域。域边界覆盖缺失要通过 coverage 图揭示。
6. **时间变化**：禁用未更新探针的旧值可避免无证旧缓存，但可能在视锥边界产生覆盖变化。尚未验证移动相机、快速转向、动态灯/几何；没有时间滤波、迟滞或流式驻留策略。
7. **方向预算**：base 4×4 方向很低；固定方向会有方向混叠，不能把确定性采样等同无伪影。四子分区映射通过不等于余弦积分对所有法线精确。
